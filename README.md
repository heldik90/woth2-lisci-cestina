# Liščí čeština — Way of the Hunter 2

Community Czech translation sources for **Way of the Hunter 2**. / Zdrojové soubory komunitní češtiny pro **Way of the Hunter 2**.

**Snapshot: revision 164, 5 October 2026.** This repository is intended for translation review, community corrections, and discussion with Nine Rocks Games. It contains translation text and localization metadata. It is not an installation package.

## For Nine Rocks Games

Thank you, Nine Rocks Games, for your work on Way of the Hunter. We would be happy to offer this community Czech translation for possible integration into the game, so console players could enjoy it too. Official integration would be handled by the game team.

The `.po` files can be reviewed directly on GitHub or opened in a PO editor such as Poedit. English source text is stored in `msgid`, the Czech translation in `msgstr`, and localization identifiers in `msgctxt`. The original identifiers are preserved for review and integration.

The initial drafts used automated translation. They have since undergone iterative language checks and corrections, including comparisons with the English source and available Polish/German catalogs. Filled entries and recorded checks do not guarantee error-free wording or correct display in every game scene.

## Pro českou komunitu

Tady najdete zdrojové soubory Liščí češtiny. Můžete porovnat český překlad s anglickým originálem, hlásit chyby přes **Issues** a navrhovat opravy pomocí **pull requestů**. Podrobnosti jsou v [CONTRIBUTING.md](CONTRIBUTING.md).

Tento repozitář obsahuje podklady pro posouzení a úpravy překladu, nikoli hotový instalátor. Oficiální začlenění češtiny do hry, včetně konzolí, je námětem k jednání s vývojáři; zatím není potvrzené.

## Coverage / Pokrytí

The existing build coverage report records **7,583 / 7,583 filled active entries** across the five game localization resources. The auxiliary catalog is excluded because it includes repeated and unused entries. The coverage report explains the counting method and its limitations. This is a completeness measure, not a promise of perfect translation or support for every future game update.

Zpráva o sestavení uvádí **7 583 / 7 583 vyplněných aktivních položek** v pěti herních lokalizacích. Pomocný katalog obsahuje také opakované a nepoužité položky, proto se do tohoto čísla nezapočítává. Vyplnění všech položek neznamená bezchybnost ani ověření všech scén ve hře.
